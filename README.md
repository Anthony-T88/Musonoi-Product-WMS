# Musonoi Product WMS

## 版本更新

每次发布在此处按版本倒序记录主要业务变化、用户可见修复和必要的升级提示。

### V4.8.8

- V4.8.8-ui7 修正 BP 表打印分页，放大企业 Logo，合计和签字随最后一行车辆明细打印。铜钴出库预览精简装箱单和下载入口，清关批次列表负责生成单证，单据详情用于查看和打印。统一「单据详情」按钮文案，精简各页面重复说明。
- V4.8.8-ui6 「商业发票与装箱单」的批次列表显示装车日期，模板入口移到筛选栏上方右侧。BP 打印恢复原样张的公司登记及联系资料，归档展开显示装车日期，代理簿移至编制及修订。许可证的本地和离岸银行 SWIFT 号随记录簿账户带入，新生成及修订的阴极铜商业发票取对应许可证档案的银行资料。升级包含 204 号增量迁移。
- V4.8.8-ui5 清关默认进入装箱单，装箱单模板入口移入其列表。BP 表分待创建和已创建批次，展示净重、毛重与关联装箱单号。创建时锁定来源批次，修订沿用原编号和车辆明细。新增独立的 BP 表模板权限。许可证的开证和离岸银行账户名随记录簿联动，办证资料按银行成组。升级包含 202、203 号增量迁移。首次启用 BP 编制时，请按已批准的 Excel 样张保存铜、钴两套固定模板资料。
- V4.8.8-ui4 按确认方案更新铜钴装箱单工作台。支持按编号、客户、单据状态和创建日期筛选，待生成优先。选择单据后可查看关联与运输资料、归档版本，并进入原办理和打印页面。
- V4.8.8-ui3 修复铜钴装车单预览及详情入口。清关按钮采用常规尺寸，BP 表限同一客户编制，归档可筛选和展开批次。清关菜单页内切换，精简列表查询及装车详情重复请求。
- V4.8.8-ui2 改进铜钴 BP 表编制和打印。清关导航使用紧凑单行按钮，编号自动建议并可手工更改，按需补充表头和车辆资料。打印沿用附件版式，只输出实际车辆行，少量明细尽量在一页内排完。
- V4.8.8-ui1 修复铜钴出门证的三联二等分连续纸打印。表格沿 241.3 毫米纸幅横排，每份走纸 139.7 毫米，打印窗口沿用打印机纸型的原方向。
- 装车单展开可查看关联计划及运输详情。铜钴派车导入保存运输商和目的地，缺失资料由销售补全，装车计划按派车车辆自动带入并允许修改。
- 新增清关单据管理，集中办理铜钴装箱单及模板。物流经理已审批的批次可多选编制 BP 表，自动带入明细，核对修改后归档并打印。
- 车辆出厂管理可按批次号查看和检索在线及历史单据。备货计划按批次号、销售计划号、发运月、客户和审批状态筛选。
- 销售计划支持按派车车牌、发运月份、客户和合同自动关联唯一匹配的历史装箱单。多趟冲突保留人工核对，开票仍由销售确认。

### V4.8.7

- V4.8.7-ui3：终审前取消备货作业后，原计划和批次号可直接重用。铜钴终审后可由现场主管申请整批撤销、物流经理审批，保留实物和历史记录，重新备货关联新批次。
- 权限编辑在启用或停用时列出实际需要同步调整的权限。移除旧打印配置，确认实际出厂可独立配置。阴极铜未锁定捆包可申请更正片数、铅封号及生产日期，由生产管理部经理审核后生效。
- 新建备货计划的销售计划选项显示发运月份。
- 修复铜、钴出门证连续纸打印。按 9.5 × 5.5 英寸横向单联排版，表格和签字栏完整打印在一页。
- 商业发票净重打印为三位小数，运输商按一行显示。新生成的发票从关联许可证档案读取本地及离岸银行资料。
- 业务单据列表按待处理、在线、历史导入排序，各组默认按创建时间倒序。出门证统一使用浏览器打印窗口。
- 铜、钴库存查询默认显示在库，地图货位明细随页面滚动并优化中英文文案。许可证统计移到筛选上方，可分配额度显示四位小数。到期提醒移到顶部操作行，历史装车许可证号入口下线。

### V4.8.6-ui2

- 商业发票在系统内按模板纸张缩放为一页，适用于新发票和已有发票。新生成的 Excel 发票也默认按一页宽、一页高打印。装箱单按明细长度分页。

### V4.8.6-ui1

- 装车单显示关联到场登记或装车快照中的司机。钴基础资料独立读取仓库、库区和货位。
- 铜钴库存地图均提供客户选择。钴地图显示常用筛选并优化缩放。铜地图和备货、移库、盘点等单据统一显示 P3 货位。清理旧预览角色、离线预览导出、导航占位入口、重复的库存客户筛选及其样式。旧装车创建链接进入当前计划匹配流程，钴基础资料旧编辑书签返回对应列表。

### V4.8.6

- 界面和标签按部署状态显示预上线环境，库存导出区分预上线录入和历史导入。离线预览采用独立提示。

- 车辆出厂列表直接统计有效历史出库记录。历史详情链接打开对应出库单，桌面筛选按一行排列。
- 许可证创建入口更名为「新建出口许可证档案」。记录簿调整行操作的位置，已用量和剩余量显示四位小数。
- 历史导入列表只显示一组分页控件，并按当前页汇总明细重量。车辆出厂列表用同一次查询返回记录、状态统计和客户筛选项。
- 优化铜钴总览图表的悬浮提示和重绘，修复页面窄屏溢出、部分英文显示和按钮对齐问题。

## V4.7.2 开发基线

V4.7.2 从 V4.7.1-ui1（迁移 181）增量开发，新增独立铜钴出口许可证、审批、额度预占与核销。使用许可证的新装车计划由后端分配发票号，现有单据编号和 UUID 保留。运行时要求迁移 182。

许可证核销、销售开票确认、ARECOMS 确认和正式出库分别保留独立依据。迁移给指定岗位新增权限，并沿用现有授权变更后的重新登录规则。

修复钴匹配审核目录、代理登录限流、未知ARECOMS统计、真实业务审计范围及授权连接异常清理。业务状态机与独立审核规则保留，注册申请仍仅系统管理员审批。

V4.7.1 完整继承现有 178 条迁移及其校验值。原 r2 加密 TEST 备份保持第 172 号迁移基线。rc3 自动验收使用独立合成数据，历史备份恢复由授权环境复核。

测试需要Node.js >=22、pnpm11.25.0和独立TEST PostgreSQL。运行pnpm install --frozen-lockfile、pnpm test、pnpm run verify:integrity；设置报告所述测试环境后pnpm run test:acceptance创建随机隔离库执行完整验收。

GitHub Actions使用全新临时数据库及随机遮蔽密码，安排真实Docker构建和合成生产模式TLS启动。实际通过与否以Draft PR检查记录和交付报告为准，配置检查不能替代镜像实测。

代理默认不受信任。部署前按Nginx真正连接应用的来源IP填写TRUSTED_PROXY_IPS（精确IP，无网段或通配符），并覆盖转发头。V4.7.1 交付范围为本地 TEST。
