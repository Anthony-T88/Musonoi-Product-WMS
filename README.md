# Musonoi Product WMS

## 版本更新

每次发布在此处按版本倒序记录主要业务变化、用户可见修复和必要的升级提示。

### V4.9.0-ui13

- 阴极铜捆包的铅封号改正生效后，系统释放该捆包原先占用且已无业务使用的旧铅封号，其他捆包可在备货时使用。仍有效的占用继续校验，封号更正记录继续保留。
- 增量迁移 224 清理有更正记录可核实的旧占用，保留有效出库单证和历史冲突记录。

### V4.9.0-ui12

- 系统管理员在具有相应操作权限和数据范围时，可审核自己提交的出库日期更正及其他业务单据。需要多级审批的单据仍按顺序办理，每一级分别记录在案。
- 增量迁移 223 为管理员补齐原有回避规则中的例外，涉及出库日期更正、铜出库更正与返场核验、钴金属量确认和整批撤销备货等仍需单独校验的业务。现有角色授权和业务记录保留。

### V4.9.0-ui11

- 铜钴「出库日期申报」可填写过去、当天或未来的有效日期。正式出库后，车辆统计、发运报表、商业发票与装箱单取申报日期。
- 在线正式出库单支持「出库日期更正」。物流经理审核后由生产管理部经理终审，终审通过后新日期生效。已归档单证保留原修订，当前发运日期变化时可重新生成。扣库时间和车辆实际出厂时间保留各自的原有记录。
- 同时授予捆包更正申请与审核权限后，同一账号可提交和审核自己的更正。升级包含 222 号增量迁移。

### V4.9.0-ui10

- 角色权限管理允许为任意岗位配置现行业务权限，原岗位名单显示为建议。捆包更正、钴作业审核、销售及出厂等业务按实际授予的权限办理。
- 备货计划建立和审核使用独立权限，升级时继承原有办理资格。项目、仓库和客户数据范围及业务流程校验继续生效。升级包含 221 号增量迁移。

### V4.9.0-ui9

- 钴金属量管理新增独立的查看和录入权限，物流办公室操作员可在授权范围内查询库存与正式出库记录，录入 ARECOMS 实测值并提交审批。「系统管理 → 角色权限管理」可调整这两项权限。升级包含 220 号增量迁移。
- 角色权限管理在每个岗位下列出所有现行权限。仅限特定岗位办理的权限显示适用岗位，在其他岗位中不可勾选。

### V4.9.0-ui8

- 阴极铜库存地图的「新生产捆包堆存区」共享卡显示区域名和捆数，点击查看该区捆包。页面和地图 PDF 的「占用货位明细」均排除该区域，剩余捆包堆存区继续按客户和批次显示。

### V4.9.0-ui7

- 英文界面与相关报表把「出库」统一为 Stock Issue，继续识别旧 Excel 中的 Outbound 表述。
- 语言菜单新增 Français，语言名固定以本名显示并随账户保存。
- 阴极铜手工入库和 Excel 入库校验捆包号与生产日期。生产日期按捆包号的年份和年内日序定位，再顺延一天。编号 MUS-2026-325-34 对应 2026-11-22。
- BP 表的 Excel 下载与系统打印共用列序、签署区和 A4 横向排版。铜钴待办中的备货作业与出库显示批次号。
- 阴极铜库存地图的占用明细按客户分组，各批次显示捆数与净重。地图 PDF 同步显示批次净重，并使用「新生产捆包堆存区」和「剩余捆包堆存区」。
- 取消总经理权限变更审批模块。获授权的管理员可直接维护权限，原审批记录保留，待审请求归档且不执行。升级包含 218、219 号增量迁移。

### V4.9.0-ui6

- 铜钴「备货计划」菜单提示当前账号可办理的待审批计划数。「计划状态」列显示状态及已关联备货单入口。创建备货单可从原办理入口操作。
- 「系统管理 → 报表邮件」采用已确认的设计，分为「发送计划」与「服务器邮箱」两个页签。发送计划支持逐项编辑、启停和查看下次计划发送时间，选择收件账号时显示注册邮箱。

### V4.9.0-ui5

- 铜钴装车计划仅可选择已完成备货且仍可装车的批次。提交时重新核验批次状态。
- 装车计划取消后，未正式使用的发票号可重新录入。旧计划、许可证分配历史和已办理单证保留。升级包含 216、217 号增量迁移。

### V4.9.0-ui4

- 铜钴备货计划以颜色区分计划状态。未创建备货单的计划显示「待创建备货单」，关联单据后同步显示作业状态。备货管理在「全部」左侧显示待创建备货单计划数。
- 权限变更审批的通过和驳回按钮单行两端对齐。注册和修改密码支持 10 至 48 位字符。
- 管理员可在「系统管理 → 报表邮件」配置获准的服务器邮箱，并通过账户选择收件人。发送时读取账户当前注册邮箱。升级包含 215 号增量迁移，启用邮件前按[部署说明](docs/nightly-operations.md)配置主机发送策略及加密密钥。

### V4.9.0-ui3

- 发运及单证明细补齐商业发票、许可证、司机及护照、车头和两节挂车、运输商、目的地、销售计划、发运月及装车日期。
- 出入库流水按业务单据显示入库单、备货单及装箱单号码。已核实的备货流转独立列示。历史报表从原始资料与已确认关联补充字段，未核实值在页面和 Excel 注明原因。
- 管理员可在「系统管理 → 报表邮件」维护启用状态、报表、收件人和发送计划。服务器侧继续管理邮箱连接和凭据。

### V4.9.0-ui2

- 采用新版异常页提示，覆盖登录失效、权限不足、页面缺失、网络或服务异常，以及业务校验和写入结果待确认。
- 按卢本巴希时间每天零点独立备份 PostgreSQL 全量快照和上一业务日的审计及系统日志。两类加密档案分别保存至服务器硬盘上的目录。
- 新增可选的系统邮箱报表任务，支持按配置推送铜钴报表摘要。备份、恢复验证及邮件启用方式见[部署说明](docs/nightly-operations.md)。

### V4.9.0-ui1

- 阴极铜生产入库支持捆包号字母后缀。手工录入和 Excel 导入可使用 MUS-2026-370-28A 一类编号，字母统一转为大写，原号与不同后缀分别入账。升级包含 213 号迁移。
- 阴极铜捆包的片数、铅封号和生产日期可由授权操作员在库存详情申请更正，经生产管理部经理审批后生效。

### V4.9.0

- 内网访问由公司服务器现有防火墙管理。数据库强化运行角色检查并提供认证加密备份。现场配置和审计结论见 [V4.9.0 内网安全审计与上线验收](docs/v4.9.0-security.md)。
- 增加独立总经理账号和权限变更审批。管理端赋权、恢复、代重置密码及角色权限更新按审批生效。系统日志支持分类、请求编号检索、脱敏详情及可核对摘要的取证导出。
- 生产升级包含 211、212 号增量迁移。上线前验证现有访问入口、数据库 TLS 和备份，再通过维护入口启用总经理账号。

- 铜钴库存地图均提供客户选择。钴地图显示常用筛选并优化缩放。铜地图和备货、移库、盘点等单据统一显示 P3 货位。清理旧预览角色、离线预览导出、导航占位入口、重复的库存客户筛选及其样式。旧装车创建链接进入当前计划匹配流程，钴基础资料旧编辑书签返回对应列表。

### V4.8.6

- 界面和标签按部署状态显示预上线环境，库存导出区分预上线录入和历史导入。离线预览采用独立提示。

- 车辆出厂列表直接统计有效历史出库记录。历史详情链接打开对应出库单，桌面筛选按一行排列。
- 许可证创建入口更名为「新建出口许可证档案」。记录簿调整行操作的位置，已用量和剩余量显示四位小数。
- 历史导入列表只显示一组分页控件，并按当前页汇总明细重量。车辆出厂列表用同一次查询返回记录、状态统计和客户筛选项。
- 优化铜钴总览图表的悬浮提示和重绘，修复页面窄屏溢出、部分英文显示和按钮对齐问题。
