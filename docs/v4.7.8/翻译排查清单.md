# V4.7.8 全站翻译排查

页面范围由 [路由和角色登记](../../tests/release/uiux-inventory.json) 与 [浏览器矩阵](../../tests/release/uiux-matrix.cjs) 决定。浏览器提取实际可见的标题、标签、按钮、表头、提示和占位符，检查英文界面的中文候选。

| 范围 | 排查或处理 |
| --- | --- |
| 登录、注册、导航、系统管理 | 「中文」是固定语言选择项。历史导入移至系统管理，两种语言下使用同一入口及授权。 |
| 总览、库存查询、地图、备货 | 铜钴分开运行。库存历史来源、发运日期、只读档案以及地图筛选、提示、工具栏按当前语言渲染。 |
| 收货、销售、装车、出库、许可证 | 检查列表、详情及已登记审批场景。历史业务单据切换语言时重新渲染原路线，客户、合同、车辆和单据编号保留业务原文。 |
| 通用表格控件 | 局部页面自行管理双语，导致共享控件绕过全局翻译。生成列选择和翻页控件时读取共享译词，切换语言时同步刷新。 |
| 铜检斤 | 通用短词翻译把「卢本巴希」中的「本」切成 `This`。补全「检斤时间（卢本巴希）」及地名翻译。 |
| 报表、盘点、系统日志、权限 | 已登记页面按角色及铜钴实测，含权限拒绝、空数据及典型表单。打印模板语言沿用模板自身设置。 |
| 弹窗和抽屉 | 扫描已登记注册、权限、审批和代表性单据场景。地图详情及批量确认另由专项浏览器操作覆盖。 |

完整矩阵覆盖 154 个路由登记、137 个场景、1,536 次检查，其中 1,502 次正常渲染，34 次为预期拒绝。英文页面的可见中文候选仅为语言选项「中文」。完整检查使用已登记的角色和业务状态，其他状态组合仍以实际操作核对。参见[逐场景扫描结果](evidence/site-audit.json)。
