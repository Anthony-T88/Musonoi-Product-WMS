# V4.8.1 发布与验收

本版本以 V4.8.0 为基线，按已确认方案更新统计报表。统计报表继续使用 /reports 地址。历史装箱单从既有历史台账读取，报表无新增数据库迁移。现有迁移链末项为 190_v478_historical_backfill.sql。

## 使用

- 切换阴极铜或氢氧化钴，再选择发运及单证、出入库流水、收发存与对账、盘点与差异或销售与履约。
- 发运默认按发运日汇总，也可按客户、合同、车辆或批次号分组。汇总行可查看该组明细。批次组车次可能重叠，发运总车次去重。
- 导出使用当前筛选和明细范围。中文工作表为「汇总」「明细」，英文为 Summary 和 Detail。日期和已知重量保存为 Excel 日期和数字。
- 历史凭据中无原始收货日期的单据从发运日追溯。历史出库单独列示。无已确认销售计划关联的历史发运可在销售明细查看。履约率根据正式开票确认计算。
- 用户与角色的现有授权规则继续适用。收发存和盘点受仓库完整范围约束。导出需具备原有导出权限。

## 验证

- 本地 TEST 帐户管理员在真实浏览器验证五个分类、五种分组、明细下钻和清除、中文下载及 390 像素布局。
- 本地 PostgreSQL 验证铜钴两产品的五类查询及 Excel、英文工作簿结构、非授权账号拒绝。独立 TEST 样本分别使用铜 XLS 与钴 XLSX 装箱单，通过历史导入 API 核对发运、流水、对账、销售和 Excel。盘点所用数据为盘点快照及实盘记录。
- 本地交付数据库保留唯一具完整项目授权的系统管理员。其余 26 个账户已删除访问、清理联系方式及原凭据，并保留历史记录引用。清理前备份存放在本机受保护的运行目录。账号、会话、数据库与原装箱单均不随 Git 源码交付。
- 用户操作请查阅同目录的中英双语 Word 手册。
