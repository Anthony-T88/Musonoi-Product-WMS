# 许可证与销售计划页面方案

| 方案 | 当前实现 | 确认后的组件调整 |
| --- | --- | --- |
| [出口许可证管理](previews/licenses.html) | `dist/export-licenses.js` 负责台账、申请、审批、附件和明细。`server/export-licenses.cjs` 已按产品及授权范围分页。 | 在原路由内调整统计、筛选和台账顺序。详情分别展示资料、额度、关联装车计划和办理记录。保留申请、签发、延期、关证、核销、更正、附件和历史记录。统计按产品与计量口径分别展示。 |
| [销售计划管理](previews/sales.html) | 铜销售计划由 `dist/ux10-sales.js` 等现有组件呈现，钴产品使用 `dist/cobalt-sales-ui.js`，履约口径由现有报表和开票确认接口提供。 | 原查询和权限框架内增加汇总行，表格保留计划、客户、合同、月份与审批状态。按业务需要复用表格分页、筛选状态和当前产品。 |
| [销售计划详情](previews/sales-detail.html) | 装车关联、正式出库批次和销售开票确认由现有产品路由和 `server/sales-invoices.cjs` 提供。 | 将详情分为计划资料、执行数据、逐车开票确认和关联记录。装车计划、许可证、装箱单和审批按已有 UUID 跳转。 |

正式出库量取已完成正式出库的记录。销售履约量取已由销售确认开票的有效记录。示意图用两个指标分别呈现这两个口径。许可证额度继续展示已使用、有效预占、待核销、剩余和可分配。形式发票号和装车发票号保留各自字段及既有编号规则。

三个页面可在本地浏览器打开，使用合成数据和现有设计变量。页面改版处于待确认阶段。当前候选中的许可证改动限于导航、加载提示与查询优化。
