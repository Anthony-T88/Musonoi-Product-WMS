# 许可证与销售计划改版

| 方案 | 当前实现 | 已实施调整 |
| --- | --- | --- |
| [出口许可证管理](previews/licenses.html) | `dist/export-licenses.js` 负责台账、申请、审批、附件和明细。`server/export-licenses.cjs` 已按产品及授权范围分页。 | 在原路由内调整统计、筛选和台账顺序。详情分别展示资料、额度、关联装车计划和办理记录。保留申请、签发、延期、关证、核销、更正、附件和历史记录。统计按产品与计量口径分别展示。 |
| [登记许可证申请](previews/license-application.html) | 台账主操作进入现有申请路由，买家由所选有效合同确定，按当前产品和授权筛选合同。 | 表单分为申请资料、数量与金额、办证资料。保存后进入详情，状态为「申请中」。许可证号和有效期在签发时登记。 |
| [销售计划管理](previews/sales.html) | 铜钴计划列表共用 `dist/ui468.js`，详情共用 `dist/ux10-sales.js`。执行数据复用有效正式出库和销售开票确认记录。 | 原查询和权限框架内增加汇总行，表格保留计划、客户、合同、月份与审批状态。每条计划的操作列并排显示查看详情和派车管理。按业务需要复用表格分页、筛选状态和当前产品。 |
| [销售计划详情](previews/sales-detail.html) | 装车关联、正式出库批次和销售开票确认由现有产品路由和 `server/sales-invoices.cjs` 提供。 | 详情顶部提供派车管理入口。将详情分为计划资料、执行数据、逐车开票确认和关联记录。装车计划、许可证、装箱单和审批按已有 UUID 跳转。 |

派车管理按所选销售计划进入现有的 `/sales-plans/:id/dispatch`。阴极铜和氢氧化钴均按现有派车权限展示入口，发运月份取销售计划。

办证资料有七个选择框，分别为开证清关公司、开证银行、开证银行账户号、离岸银行、离岸银行账户号、目的地和备注。每个字段旁有自己的记录簿。用户先在记录簿新增记录，再回到申请表选择。两个账户号分别按已选的开证银行或离岸银行筛选，换银行时清除不匹配的账户。正式页面把记录簿保存在数据库中。同一项目、产品和客户下可跨合同复用。许可证保存所选记录及当时的资料值，已有单据仍可查看原资料。

正式出库量取已完成正式出库的记录。销售履约量取已由销售确认开票的有效记录。示意图用两个指标分别呈现这两个口径。许可证额度继续展示已使用、有效预占、待核销、剩余和可分配。形式发票号和装车发票号保留各自字段及既有编号规则。

预览可在本地浏览器打开，使用合成数据和现有设计变量。申请页支持切换阴极铜、氢氧化钴和试填示例字段。已在 V4.7.3-ui2 的独立本地 TEST 实施。预览仍保留作为设计参考。
