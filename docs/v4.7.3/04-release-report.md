## 迁移 184 候选的许可证性能对比

Chrome 使用两套独立 TEST，各有 600 条合成许可证。API 延时取 7 次请求中位数。SQL 时间为 `EXPLAIN ANALYZE` 执行时间合计。弱网列使用模拟 180 毫秒延迟和 2 Mbps 下行。数量、筛选结果、状态和计量汇总在两套实例一致。

| 指标 | V4.7.2 | V4.7.3 |
| --- | ---: | ---: |
| 列表业务 SQL | 5 条 | 2 条 |
| SQL 执行合计 | 11.19 毫秒 | 5.35 毫秒 |
| 列表 API 中位延时 | 34.65 毫秒 | 14.53 毫秒 |
| 本机点击到许可证标题可见 | 890 毫秒 | 322 毫秒 |
| 本机点击到列表可见 | 892 毫秒 | 396 毫秒 |
| 模拟跨境网络点击到列表可见 | 28,999 毫秒 | 850 毫秒 |
| 本机切换网络请求 | 193 | 1 |
| 本机切换文档重载 | 1 | 0 |
| 本机切换传输量 | 5.09 MB | 47.5 KB |

补充浏览器测量如下，单位为毫秒。登录计入进入销售计划页的初始化。信息总览、销售计划和库存地图从已登录状态计时。
