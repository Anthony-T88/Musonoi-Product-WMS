开发分支 `feature/v4.7.3-online-optimization`，基线 `3e8f0d6d1a667828c1ba9f4cd42441af0d74eaea`。本地候选运行在 `http://127.0.0.1:4180`，使用独立恢复的合成 TEST 数据库。

| 任务 | 实施结果与核对 |
| --- | --- |
| F01 注册 | 共享字段规则、同时显示多个错误、字段修改后清除错误、重复申请拒绝、连接失败单独提示。申请保留原管理员审批流程。既有 API 调用可继续提交单个密码，网页表单提交并校验两次密码。 |
| F02 登录 | 登录响应复用授权资料，加载状态覆盖首屏直到目标路由完成，脚本并行下载并按原依赖顺序执行。测试覆盖直接访问受保护页面、慢网登录及刷新。 |
| F03 许可证 | 同页客户端切换、加载骨架、现有分页与查询条件。列表和统计共用只读事务，两条 SQL 完成原五条 SQL 的工作。许可证关联与额度继续按原规则计算。 |
| F04 会话 | 登录替换在数据库事务中完成。唯一索引确保只有一个当前会话，旧会话下次请求收到失效提示。已核对双设备、并发登录、旧写入拒绝、同浏览器共享 CSRF、不同账号、退出和重启。 |
| F05 铜地图 | P5 名称与数量分行居中，缩小时保留可读数量与可访问名称，地图原有区域关系和点击详情保留。 |
| F06 许可证改版 | [预览与组件方案](02-design-review.md) 待确认。 |
| F07 铜剩余捆包 | P3 聚合显示，现有现场装车审核事务释放符合条件的捆包，原始货权、袋捆编号、重量、铅封及批次历史保留。再次备货同时校验真实客户和原有效占用。 |
| F08 地图数量 | 新建生产入库时写入 P5 地图关联，兼容已有未映射入库区。数量来自库存查询口径，区域有记录时显示实际数量，查询失败使用现有加载错误提示。 |
| F09 改名 | 铜界面显示新生产捆包堆存区和 New Production Bundles Stock Area。已同步核对地图、库位筛选、铜库存 CSV/XLSX 和入库模板。历史货位主键和内部编码保留。 |
| F10 销售计划改版 | [列表与详情预览](02-design-review.md) 待确认。 |
