# 穆松尼 WMS V4.8.3

## V4.8.3-ui1

- 铜钴历史装箱单预览标注重复捆包、袋号、铅封号及关联单据。管理员可以逐份复核并填写原因。重复实物编号保留原表行并排除重复的库存、净重和额度统计。只有铅封号重复且实物编号有效的行仍按实物计量。装箱单号冲突、无效日期、缺少编号及无效重量仍须修正。
- 钴库存地图会清除失效的仓库、库区和货位筛选，并恢复当前授权范围的默认图。货位和库存来源仍为现有配置及业务记录。
- 迁移版本仍为 `195_v482_dispatch_vehicle_month.sql`。已运行 V4.8.3 的预生产实例使用 `deploy/upgrade-preproduction-v483.sh <完整提交 SHA> ui1`。脚本备份整库和上传文件，验证恢复及升级前后数据对账，再切换应用。
- `deploy/remove-unposted-test-receipt.sql` 是受限的单次 TEST 维护入口，按精确单号删除未过账且没有库存记录的测试入库单。需要已验证的备份，原单及明细写入审计日志。已有过账或库存关联的单据由脚本拒绝。

## 变更

- 阴极铜和氢氧化钴共用独立的备货计划批量录入页。出口主管和有相应权限的管理员可按备货批次号或客户查看已占用批次，按行录入或粘贴批次号。销售计划带出客户及发运月，发运月可逐行编辑。每批最多 100 行。
- 草稿逐行校验。占用冲突、表内重复、权限不足和失效销售计划均阻止整批保存。入账和审计在同一事务内完成。保存后返回备货计划列表并标记本批新增草稿。
- 历史入库、装车计划、装车单、出库单、库存档案和装箱单来源采用统一详情布局。支持打开真实关联单据，并返回原页面与原筛选。原件下载和导入纠错沿用现有管理员授权。

## 数据库及部署

迁移链保留至 `195_v482_dispatch_vehicle_month.sql`。本次两项功能沿用原有备货计划与历史回填数据表。云端若仍在 V4.8.1-ui6，应以现场迁移记录为准补齐迁移 195。

DigitalOcean 预生产站的升级入口为 `deploy/upgrade-preproduction-v483.sh`，接收完整发布提交 SHA。升级预先验证目标 Compose 项目、数据库、上传卷及 HTTPS 配置。构建镜像后预演迁移，将备份恢复到独立验证库，再切换应用。备份和核对文件保存在服务器受限目录。

迁移提交前可启动原应用。迁移提交后回退旧版本时，应在独立数据库恢复升级前备份，配套启动旧镜像。应先保全新版产生的业务写入。

## 验收

专项脚本 `tests/release/preparation-history-ui.cjs` 使用独立合成 TEST 库的铜钴样本，验证批次查询、权限、批量校验、冲突时整批回滚、并发、幂等重放及历史链路。浏览器测试通过实际页面提交草稿和打开关联单据。
