# 备货计划和历史单据详情改版方案

适用阴极铜和氢氧化钴。两项方案可分别确认后实施。

## 新建备货计划

沿用「备货管理 → 备货计划 → 新建备货计划」。左侧标题与主操作对齐。桌面上下显示批量录入表和可折叠的已用批次表，窄屏逐组换行，录入表可以横向滚动。

| 区域 | 显示及操作 |
| --- | --- |
| 批量录入 | 每行按「备货批次号、销售计划、客户、发运月份、校验结果、操作」排列。首行可为后续空行提供默认销售计划和发运月份。客户随该行销售计划带出。 |
| 快捷填写 | 支持逐行新增，也可从 Excel 复制一列批次号粘贴为多行。录入区保留行级修改和移除。 |
| 已用批次 | 可按批次号或客户查找。显示批次号、客户、发运月份、状态及来源。当前计划和历史备货作业都参与查重，同一批次只展示一行。钴的历史作业若未关联客户，客户显示「—」。仅显示有权查看的客户和单据。 |
| 校验与保存 | 对重复、已占用、编号格式错误、销售计划失效等情况，在对应行提示。确认后一次保存全部计划为草稿，任一行不通过即保留整批输入，修正后再保存。 |

保存后回到备货计划列表并突出本次创建的草稿。已有提交、审批和开工入口沿用现行规则。销售计划变更、跨项目输入或并发抢占批次时，由服务端重新校验。若冲突来源超出账号的数据范围，提示该批次号已占用。

验收包括铜钴各一次多行创建、粘贴重复批次、与现有作业冲突、不同客户、部分填写、并发保存和窄屏录入。

## 历史单据详情

继续从各业务列表打开单据。将各类历史详情接入在线详情的页首、摘要和数据表格样式。选中单据后，返回入口回到原列表上下文。页首识别单据编号和「历史导入数据」状态，关键指标和各列标题居中。业务原值按原文显示，字段标签随页面语言切换。

| 单据 | 首屏摘要 | 下方明细与来源 |
| --- | --- | --- |
| 历史入库单 | 单据编号、仓库、已知原入库日期、补录记账日、数量、净重 | 逐捆或逐袋列表，跳转同一历史链的装车与出库单。未知原入库日期显示「—」。 |
| 历史装车计划 | 计划编号、装箱单号、备货批次号、发运日期、已知客户和车牌 | 关联装车单、货物清单、合同和装箱单来源。 |
| 历史装车单 | 单据编号、装车计划、已知运输资料、实载数量与净重 | 逐捆或逐袋明细，直接进入关联计划和历史出库单。 |
| 历史出库单 | 出库编号、发运日期、车牌、装箱单号、已知客户及重量 | 出库货物明细，直接进入历史装车单和库存档案。 |
| 历史库存档案 | 铜显示捆包编号及已记录片数，钴显示备货批次号和袋数。两种产品均展示已出库状态及实际可查重量。 | 展示已记载的铅封号、关联入库、装车和出库单，以及有依据的历史事件。 |
| 导入记录与原件 | 继续由系统管理员在历史导入模块查看 | 可查原文件、导入时间、操作人、状态及源文件行号。保留既有纠错入口。 |

同一份装箱单的关联单据按实际可追溯记录提供可跳转链接。在线复核、补录日期、审批人和纸质单据已有凭据时才展示。未记录的客户、合同、重量或 ARECOMS 实际确认量沿用系统空值样式。历史详情沿用既有浏览及原件查看权限。

验收从铜、钴各一张历史装箱单进入各类详情，核对跳转、逐捆或逐袋字段、原始日期缺失、权限范围以及中英文和窄屏显示。
