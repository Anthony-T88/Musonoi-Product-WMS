# 穆松尼系统 UI 设计规范

本规范适用于阴极铜和氢氧化钴。业务名称、数量、重量、金额、单据编号和审批状态取自业务数据。统一布局时继续使用现有角色权限、计量单位和状态口径。

## 页面结构

1. 左对齐的主标题与主要操作。主标题表达页面职责，单据页用独立字段显示单号。页眉保留实际业务相关的产品或状态。
2. 标题下依次放统计摘要、筛选或工具栏、核心表格或表单。能用标题、字段和状态表达的内容就写在对应组件中。
3. 在处理对象附近显示校验结果。错误说明哪里出错及可执行的下一步。加载或筛选后保留页面骨架。
4. 详情页依次放当前节点、办理按钮、单据信息、明细、变更和审核记录。辅助记录可用原生 `details` 折叠。

## 视觉变量与组件

变量统一放在 `dist/uiux-governance.css`。专用地图、打印模板和条码页沿用各自的输出尺寸。

| 用途 | 标准 |
| --- | --- |
| 字体层级 | 页标题用标题变量，区块和卡片用分标题变量，正文、辅助文字各有独立层级。标题左对齐，数字指标可居中。数字采用等宽数字特性。 |
| 文字与底色 | 主文字、次文字、页面底色、卡片底色、边线各有独立变量。正文与背景以 4.5:1 为目标，状态同时用文字表达。 |
| 品牌与状态 | 品牌绿用于主操作及焦点。危险、待办理、完成和中性状态使用明确名称与独立语义色。 |
| 操作控件 | 保留 `.button.primary`、`.button.secondary`、`.danger` 和 `.compact`。主操作默认一处强调，常规按钮保留一致的最小触控高度。 |
| 输入与筛选 | 字段使用关联的 `label`。筛选的查询、重置、导出按顺序成组。有效业务说明放在字段旁，输入错误与对应字段关联。 |
| 间距和卡片 | 使用间距变量排列。卡片用统一边线和圆角。同一排统计卡的结构一致，单位靠近数字。 |
| 表格 | 表头保留字段和单位，操作列集中，同列对齐。表格太宽时在容器内滚动，页面宽度保持在视口内。 |
| 弹窗和侧栏 | 复用原生 `dialog` 或已有审批确认组件。标题可供读屏读取，焦点进入弹窗并回到触发控件。确认、取消保留明确标签。 |
| 响应式 | 桌面验收使用 1366×768、1440×900 和 1920×1080。900 像素及以下使用可展开的业务导航，640 像素及以下允许筛选和操作分行。另检查 390 像素，地图与表格在各自的区域滚动。 |

## 操作位置与用语

| 动作 | 布置 |
| --- | --- |
| 保存、提交、审核通过 | 在对应表单或办理区强调当前可执行动作。使用明确动词。 |
| 返回、重置、下载、导出 | 使用次级样式。下载和导出靠近相应数据，返回位于页首或表单操作区。 |
| 退回、撤销、删除 | 保留原有原因、审批和确认流程。危险样式与普通动作通过间距区隔。 |
| 无可执行动作 | 根据权限和业务状态呈现已批准的状态、等待信息或禁用控件说明。 |

清理重复内容时，先比较链接目标、事件处理、授权范围和单据状态。纯视觉重复可合并。单位、限制、风险、合规、审批和操作恢复指引保留在业务需要处。

钴产品使用备货批次、袋号和相关单据识别库存。净重显示四位小数，预计与确认钴金属量显示五位小数。界面和导出的展示精度与数据库原始数值独立。角色权限页以保存权限为主要操作，新增角色为次要操作。
