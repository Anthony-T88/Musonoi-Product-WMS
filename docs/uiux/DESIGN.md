# 穆松尼 WMS 全站设计规范

适用于 V4.7.4 及后续版本。阴极铜和氢氧化钴共用页面框架、主题、控件和反馈。单据字段、角色、状态、计量和审批规则取自对应业务模块。主题入口是 [uiux-governance.css](../../dist/uiux-governance.css)，页面组合与组件入口是 [UI46Pages](../../dist/ui46-pages.js)。

## 视觉主题

主题由应用入口加载一次。以下值以主题文件为准，页面通过变量引用，尺寸以默认根字号 16 px 换算。

| 用途 | 变量 | 当前取值 |
| --- | --- | --- |
| 字体 | `--uix-font` | 系统字体，Segoe UI，Microsoft YaHei UI，Microsoft YaHei，sans-serif |
| 页面标题 | `--uix-title`、`--uix-title-line` | clamp(1.375rem, 2vw, 1.625rem)，行高 1.25 |
| 区块标题 | `--uix-section` | 1.125rem（18 px） |
| 正文和次要文字 | `--uix-body`、`--uix-caption` | .875rem（14 px）、.8125rem（13 px） |
| 字重和行高 | `--uix-weight-emphasis`、`--uix-line`、`--uix-label-line` | 常规 400，强调 600，正文 1.45，字段标签 1.35 |
| 画布和卡片 | `--uix-canvas`、`--uix-surface`、`--uix-soft` | #f4f6f4、#fff、#eef2ef |
| 正文、辅助文字和边框 | `--uix-text`、`--uix-muted`、`--uix-border` | #23382d、#52645a、#cbd6ce |
| 主操作 | `--uix-brand`、`--uix-brand-hover`、`--uix-on-brand` | #256447、#1c4c36、#fff |
| 信息状态 | `--uix-info`、`--uix-info-soft` | #235774、#e7f0f6 |
| 成功状态 | `--uix-success`、`--uix-success-soft` | #246142、#e5f1e8 |
| 待处理状态 | `--uix-warning`、`--uix-warning-soft` | #73531d、#fff1d5 |
| 危险及错误状态 | `--uix-danger`、`--uix-danger-soft` | #952b29、#f9e6e5 |
| 键盘焦点 | `--uix-focus`、`--uix-focus-ring` | #235e87、.1875rem（3 px） |
| 间距 | `--uix-gap-xs`、`--uix-gap-sm`、`--uix-gap`、`--uix-panel-gap` | 6、10、14、18 px |

正文和可操作文本以 4.5:1 对比度为目标。状态写出名称并辅以语义色。数字使用等宽数字特性。保留用户可见焦点。

## 页面骨架

| 页面类型 | 阅读和操作顺序 | 代码入口 |
| --- | --- | --- |
| 列表 | 左对齐页标题与主要操作 → 筛选 → 表格 → 分页。现有指标摘要可紧随标题。筛选和表格共享容器边界。 | `Router.page`、`UI46Pages.list`、`.wms-page` |
| 详情 | 返回入口、单号与状态、当前操作 → 摘要 → 分组详情、关联单据和审核记录。页标题说明业务，摘要显示编号。 | `UI46Pages.identity`、`UI46Pages.factList`、`.wms-section` |
| 单据操作 | 页标题及必要说明 → 分组表单或明细 → 提交、审核或保存操作。操作位于对应业务对象附近。 | `UI46Pages.form`、`.wms-field-grid`、`UI46Pages.submit` |
| 专用工作台 | 列表和只读预览并置，窄屏把预览移到列表下方。复杂办理进入独立详情。 | `OperationWorkspace`、`.wms-preview` |

页眉最多一个主要视觉操作。使用已有审批入口及文案，角色与单据状态决定可见操作。共用「返回上一页」位于页首左侧，标题紧随其后。页面提供明确指向的返回入口时，优先使用该入口。关联记录可以折叠。

## 组件用法

### 筛选区

使用原生 form 和 label。常用字段从左到右，按钮组靠右。宽度不足时先把低频字段放入 `details` 的「更多筛选」，随后让字段组换行。查询与重置相邻，保持与字段等高。配置 `data-wms-reset` 后共享增强逻辑沿用该重置操作。保留已有查询参数及表格分页行为。

```html
<form class="filters wms-filter-row">
  <label>批次号<input name="search" type="search"></label>
  <div class="wms-filter-actions">
    <button class="button primary">查询</button>
    <a class="button secondary" data-wms-reset href="/preparation/work-plans">重置</a>
  </div>
</form>
```

### 表单、按钮与反馈

- 使用 `.user-form .form-grid.wms-field-grid`。简单字段用 `label.wms-field`，采用共享行对齐标签、控件和提示。长备注、附件及明细用 `data-field-span="full"` 跨列。字段使用原生 `required`、`readonly`、`disabled`。
- 启用 `data-wms-validation` 的表单自动为 `.wms-field` 内的原生校验生成下方说明，使用 `aria-invalid` 和 `aria-describedby`。可定位的业务字段错误使用相同语义。整单错误显示在所属操作区。注册及许可证延期使用自己的字段校验和共享错误样式。
- 主、次、危险、紧凑按钮使用 `.button.primary`、`.button.secondary`、`.button.danger-outline`、`.button.compact`。图标按钮提供可读名称。保存、提交、通过、退回、返回、查询、重置采用统一动词，审批仍显示具体办理动作。
- 组件采用 `UI46Pages.submit(event, run)` 或既有业务提交处理。处理中禁用当前操作并保留幂等请求；失败显示错误，恢复按钮和已填写内容。
- 首次加载使用页面状态。切换路由时，布局和语言处理完成后显示目标页。局部刷新保留原页面骨架。待办数量来自 `UnifiedNavigation.setTasks`，每个菜单最多一个红色角标，零项隐藏角标，读屏名称含实际数量。
- 整页空数据、无结果、权限不足和加载失败复用 `System46.stateHTML`。局部反馈用 `.wms-feedback` 配合 `role="status"` 或 `role="alert"`，让刷新和错误与所在区域关联。

### 数据表、状态和指标

- 使用原生 table、th、td 和已有滚动容器。复用 `UI46Pages.table(html, {responsive, numeric, actions})` 为列添加表头范围及语义。普通文字、编号和日期起始侧对齐，数量、重量、金额、百分比和表内已声明的数字列末侧对齐。数字列由数据列含义声明。编号即使仅含数字仍按编号呈现。
- 同列标题及数据需要居中时，通过 `UI46Pages.table` 的 `center` 列索引配置。列表履约进度使用 `<progress>` 和实际百分比文字，超额时填满进度条。排序按实际履约值，缺失值排在末尾。
- 保留完整长编号、客户、合同。文本可换行。窄屏在表格容器内滚动，或用 `responsive` 生成可访问的行内标题。每行操作集中在操作列。保留相应的业务单位和精度，空值用「—」或业务状态说明，实际零值仍显示 0。
- 用 `UI.status(code, domain, label)` 输出状态标签。业务领域定义同一状态码的含义和文案。危险操作和一般操作分开布置。
- 用现有指标组保持同组高度、背景、边框和文本层级。总览三张许可证卡按有效、剩余额度、即将到期排列，标题和数值水平居中，整体垂直居中。
- `UI46Pages.factList` 接收标签和由调用方生成的安全值内容，保留原数据、计量单位和未知状态。

### 弹窗与预览

短确认使用 `OperationConfirm.ask`，含标题、可执行动作、必要说明和取消。危险动作沿用既有原因、二次确认和审批规则。使用原生 dialog 并关联标题，支持 Escape 和关闭后焦点归还。已有单据只读预览采用 `.wms-preview`，读取时标记 `aria-busy`，已加载时恢复可操作。复杂长表单采用独立页面，产品切换沿用未保存内容确认。许可证及备货计划切换语言时保留当前路由，有未保存内容时提供取消或放弃后切换。

## 响应式和业务例外

- 1440×900、1280×800 和 390×844 是本规范的基础验收宽度。旧质量矩阵继续覆盖 1366 和 1920 像素。900 px 及以下导航可折叠，700 px 及以下筛选可按组换行，640 px 及以下启用已声明的窄屏表格模式，480 px 及以下库存筛选为单列。
- 铜、钴库存地图具体画布分别按 V4.7.4 方案确认。画布比例、地块顺序、货位绑定和地图悬浮信息属于专用布局。页面级键盘焦点与导航沿用公共样式。
- 铜钴地图通过 `StockMapReview` 复用定位、清除、缩放、适应画布和刷新工具栏。桌面货位详情浮在画布上，700 px 及以下放在画布下方。需放大才可读的货位文字随缩放显示，按货位号可直接定位。
- 钴地图的高级筛选使用 `wms-map-filter-row` 与 `wms-filter-actions`。筛选靠左，查询和重置靠右成组。钴地图适应画布时显示全场，狭长货位将编号竖排，放大后可平移。缩放只改变地图视区，画布尺寸固定，按钮与滚轮平滑过渡并尊重系统减少动态效果设置。铜地图使用页面顶部的货位统计、定位和缩放。
- 空侧栏的 `p46-grid` 使用单列。已有可见资料时恢复双列。数量列使用 `CountValues` 按业务字段显示整数、实际零值和空值，异常小数保留源值以供核实。历史台账使用同一套筛选、表单和滚动表格。
- 已加载的装箱单和商业发票预览由 `PackingPrint` 提供独立打印窗口，应用模板纸张、方向、边距和分页。出门证保留该单据流程中的配置与打印窗口记录。
- 打印、单证预览、标签和报表导出沿用原有输出尺寸、字体及布局。页面工具栏、状态和反馈使用共享组件。现场逐捆、逐袋作业及权限矩阵保留适于密集操作的局部表格。钴净重四位、预计及实际金属量五位。钴库存追溯使用备货批次和袋号。
- 预览工作台和库存地图的横向滚动限于相应工作区。页面级筛选、表单和业务操作仍须通过溢出和键盘检查。
- 阴极铜库存趋势的捆包数和已备货在库净重共用时间轴，左轴为捆，右轴为吨。图例对应两轴，图表数据合并为一张表。车辆和捆包计数图的刻度使用整数，明细和悬浮提示保留计数格式。铜地图两处共享堆存区的画布标题随缩放调整，工具栏保持常规字号。
- V4.7.6 铜钴库存档案详情按已确认方案使用居中档案字段和居中表格列，长编号在单元格内换行。关联入口使用可直接打开目标单据的链接，原单据路由和接口继续校验权限。
- 单据办理的草稿采用次操作「保存草稿」，草稿以「草稿」状态显示在对应单据原表，行操作提供「继续填写」。已具备业务草稿的入库单复用原保存入口，未填完整的表单可先保存填写进度。
