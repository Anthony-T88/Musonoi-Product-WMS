# V4.8.0 本地验收

开发基线为 V4.7.9 提交 `ec4a6d4`。本地地址为 [127.0.0.1:4191](http://127.0.0.1:4191/)，资源版本 4.8.0-ui1，数据库沿用迁移 190。

| 项目 | 验收 |
| --- | --- |
| 铜钴总览 | 「已出库重量」统一命名，钴总览移除「销售计划履约」卡。 |
| 历史库存与发运 | 原始装箱单批次号可检索和排序。铜钴发运报表及 Excel 纳入历史导入，铜出入库流水逐捆列示。有依据的原始入库日可进入入库流水。实时库存账和月度勾稽按在线记账记录计算。 |
| 实际数据对账 | 2026-11-11 的铜历史发运共 6 批、109 捆、221.5665 MT，按批次号导出后对照一致。第 993 批库存筛选返回 19 捆，原始入库日期为空。钴历史报表使用隔离合成样本验证导出。 |
| 共享界面 | 页面切换先完成目标页布局与语言处理。浏览器逐帧验证旧布局未在指定路由显示。通用报表移除冗余「统计口径」说明，保留对账需要的起点和未知值说明。 |
| 翻译与账户权限 | 批次号统一使用 Lot Number。删除角色权限页的只读数据访问范围卡和对应查询，账户的项目、仓库和客户权限仍按原规则执行。 |
| 钴地图 | 全景与放大共用固定画布，按钮及滚轮平滑改变视区。Chrome 实测经过多个中间缩放帧，可拖动、缩回全场、打开货位详情。 |
| 测试数据 | 独立副本删除 100 张合成历史装箱单和关联投影、5 张合成铜入库单、2 组钴备货测试数据及 1 份草稿等。保留真实历史装箱单、现有账户、权限、地图及审计日志。原库与清理前备份可用于恢复。 |
| 性能 | 版本化公开资源允许浏览器长期缓存。页面、业务 API 与更新脚本继续采用 no-store。钴报表按销售计划预分组，角色权限列表移除无用的范围汇总。单机 7 次请求中位数为铜库存 99.7 ms、铜发运报表 7.0 ms、钴报表 16.0 ms、角色权限 4.2 ms。未以生产网络或服务器负载实测。 |

## 验收结果

- 139 项发布回归通过。业务浏览器回归包含备货审批及退回后键盘重新提交。鼠标重新提交在并行运行浏览器测试时曾出现确认框超时，单独按键盘路径复验通过。
- 全站布局门禁通过，覆盖 154 条注册路由、137 个场景、1,536 次检查和 724 张截图。英文残留扫描仅报出语言切换项「中文」。
- 另通过铜钴历史报表与 Excel 导出、历史批次检索、页面过渡帧与钴地图缩放专项。全站浏览器结果以采集时的页面和数据样本为范围。
