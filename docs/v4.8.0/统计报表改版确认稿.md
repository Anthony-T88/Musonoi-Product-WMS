# 穆松尼 WMS 统计报表改版方案

**状态：待确认。** V4.8.0 修复现有报表查询和导出漏数。以下分类、页面和模板用于评审。

参考 Oracle WMS 对在库快照、库存变动历史、出库装载和盘点资料的划分，以及 Dynamics 365 对汇总、明细下钻和大数据量导出的做法。  
[Oracle Warehouse Management Cloud Online Help](https://docs.oracle.com/en/cloud/saas/warehouse-management/26b/owmol/online-help.pdf) · [Microsoft Dynamics 365 库存库龄报表](https://learn.microsoft.com/en-us/dynamics365/supply-chain/cost-management/inventory-aging-report-storage)

## 页面与报表类型

进入「统计报表」后，按业务目的选择类别。筛选栏沿用全站设计规范。常用筛选包含期间、客户、合同号和批次号，按权限和报表类型显示仓库、货位及状态。页面先展示汇总，再展示明细。点击汇总行进入相同筛选范围下的单据或捆包、吨包明细。

| 报表 | 适用场景 | 汇总与主要字段 |
| --- | --- | --- |
| 在库快照与货位 | 查指定时点的库存，按仓库或客户盘查 | 仓库、货位、客户、批次号、库存状态、捆包／袋数、净重、重量待确认数量 |
| 出入库流水 | 核对每日入库、出库和调整 | 业务日期、事件类型、单据号、批次号、捆包号／袋号、数量、净重、来源 |
| 发运及单证 | 按期间、客户、合同或车牌对账 | 发运日期、客户、合同号、车辆、批次号、装箱单号、数量、毛重、净重、单证状态 |
| 收发存与月度对账 | 核对在线库存账期初、变动、期末 | 期初、入库、出库、返场、调整、范围流转、期末和差额 |
| 备货与履约 | 查看计划及各作业节点进展 | 销售计划、发运月、客户、合同、批次号、计划净重、备货、装车、出库和确认开票净重 |
| 盘点差异 | 跟进差异、处置及冻结报告 | 盘点单、仓库、差异类型、数量、净重差、处理状态、冻结报告 |
| 钴金属量 | 核对实物净重与金属量 | 批次号、实物净重、预计金属量、ARECOMS 实际确认量、确认状态 |

## 模板

- **期间汇总模板**。首页显示产品、期间、筛选条件和生成时点。表格依次展示分组、小计和总计。按日、月、客户、合同切换时沿用相同字段和单位。
- **明细模板**。一行对应一张发运单或一个实物单位。冻结表头，启用筛选，单据号、批次号、车牌和铅封按文本保存，日期和净重按可排序的数据类型保存。
- **月度对账模板**。第一张表呈现在线账勾稽，后续表展示在线变动及装箱单历史发运。历史导入以发运日归属，原始入库日有依据才计入入库流水。历史装箱单有数量和净重，缺失的审批日期、期初库存及 ARECOMS 确认量留空。
- **铜钴共用显示规范**。批次号英文使用 Lot Number，计数用整数，净重按 MT 保留四位，钴金属量保留五位。使用「数据来源」列区分在线单据与历史导入。导出的汇总和明细来自同一次筛选，保留必要的单位及历史边界。

## 请确认的取舍

1. 首批是否实施「发运及单证」「出入库流水」「收发存与月度对账」，然后扩展到其余四类。
2. 发运默认按日汇总，支持客户、合同、车辆和批次号分组。请确认是否要将默认改为按客户。
3. Excel 默认提供「汇总」「明细」两张工作表。是否需要按客户自动拆分工作表。
