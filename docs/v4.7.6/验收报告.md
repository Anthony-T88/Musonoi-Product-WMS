## 复验入口

隔离 TEST 服务地址为 `http://127.0.0.1:4187/`。`/api/v1/config` 返回版本，`/api/v1/health` 检查数据库连通。合成样本配置和凭据保存在本机运行目录。

```powershell
node scripts/verify-release.cjs
node tests/release/uiux-quality.cjs static
node scripts/run-release-tests.cjs acceptance
node tests/release/v476-browser.cjs
```

后两条命令需要项目测试规定的本地 PostgreSQL TEST 管理连接、应用密码和 Chrome。专项脚本要求 V4.7.6 独立 TEST 服务及 `.runtime/v476-test-config.json` 中的合成账户与数据库配置。
