# V4.7.6 权限矩阵与变更

可机器核查的[角色授予与界面权限目录](permissions-test-matrix.json)来自 V4.7.6 合成 TEST，包含 11 个内置岗位及当前目录定义。产品上下文、用户授权的项目、仓库和客户范围始终参与业务数据校验。

| 模块与页面 | 实际操作 | 权限及状态约束 |
| --- | --- | --- |
| 铜钴备货计划 `/preparation/work-plans` | 新建、保存草稿、编辑、提交 | 出口主管或管理员具备 `plan:read`。编辑和提交限本人草稿或退回计划 |
| 铜钴备货计划 | 通过或退回 | 物流经理或管理员具备 `allocation:review`，计划待审且禁止自审 |
| 铜钴备货计划和作业 | 创建备货单、查看关联作业 | 铜 `allocation:write`，钴 `co:create`。仅获批且未领用计划可生成，查阅关联作业按对应读取权限 |
| 铜钴库存档案 | 查看、关联跳转和导出 | 铜 `inventory:read`，钴 `co:read`。单据入口按目标页面权限，接口复核授权范围。导出仍需 `inventory:export` |
| 装车计划和装车单 | 查看、草稿、创建、匹配、审核 | 计划读取 `loading-plan:read`，写入 `loading-plan:write`，匹配 `loading-plan:match`，装车单 `load:read`／`load:write`／`load:review`。钴现场审批另校验岗位和业务状态 |
| 铜钴车辆到厂 | 查看、保存草稿、登记和修改 | `vehicle-arrival:read`、`vehicle-arrival:write`，按派车记录的产品、客户范围和实际到厂状态办理 |
| 车辆离场和正式出库 | 申报、物流复核、终审、归档 | `load:execute`、`outbound:logistics-review`、`outbound:production-approve`、`outbound:read` 对应实际流程；继续校验处理人分离 |
| 库存盘点 | 查看、新建、草稿、实盘、审核及导出 | `stocktake:read`、`stocktake:write`、`stocktake:review`。正式调整由原调整权限及独立审批保护 |
| 出口许可证 | 查看、申请、草稿、编辑、延期和审批 | `export-license:read`、`export-license:write`、`export-license:approve`，按当前产品、许可状态和数据范围办理 |
| 商业发票及装箱单 | 查看、保存办理草稿、生成、修订、下载及浏览器打印 | 复用实际单据读取、`document:generate` 与 `inventory:export`，生成时校验归档版本 |
| 出门证 | 生成、预览、下载、打印及确认实际出厂 | `gate:issue`、`gate:read`、`gate:print`、`gate:exit`。销售确认仍按现有岗位和凭据 |
| 账户管理和注册申请待办 | 新建、管理账号、审批注册 | `users:manage`。权限编辑使用 `roles:manage`。现有待办计数按同一审批权限生成 |
| 全模块草稿 | 列表、续填、修改、删除、转正式提交 | 复用对应入口权限，草稿本身限创建账户及当前产品，接口校验版本与已填关联 |

变更

- 管理员备货计划授权由后端统一判定，页面使用同一动作结果。自审、数据范围和库存领用条件继续参与校验。
- 更新了库存档案、备货计划、草稿、许可证、单证办理和出门证打印的中英文权限名称。移除的独立打印机菜单对应的历史配置权限仍服务于兼容接口与旧打印记录，在目录中标为历史打印配置。
- 当前账户模型以 `users.role_code` 关联单一岗位。多岗位并集在此基线中无运行入口。复验采用管理员、出口主管、物流经理及只读角色的不同账号和产品上下文。
