# 正文宽度与侧栏确认稿

[交互确认稿](content-width-proposal.html)使用合成 TEST 的装车单关联计划数据。可以在桌面切换无侧栏、侧栏打开、侧栏关闭和 390 像素窄屏。

| 页面或组件 | 当前宽度来源 | 拟采用方案 |
| --- | --- | --- |
| 铜钴入库工作台 `/receipts`、铜备货工作台 `/preparation`、铜钴出库工作台 `/outbounds` | `OperationWorkspace` 无选中单据也挂载只读预览面板，`.op-split` 保留第二列 | 默认正文全宽。选择有权查看的单据后展示预览，关闭后恢复正文宽度 |
| 共享单据详情与操作页 `UI46Pages.grid` | 初始双列，现有空侧栏判断以子节点数量为准。子节点被权限、样式或状态隐藏时仍会占位 | 按真实可见内容设置单列或双列，加载完成和操作后重新计算 |
| 基础资料编辑 `/customers/master-data/:type/:id` | `System46.masterForm` 固定分配说明栏 | 说明栏有持续可见内容时保留。当前说明栏属持续展示场景 |
| 出门证办理 `/outbounds?view=departures` | 办理区承担持续显示的出厂操作和历史 | 有内容保留双列，窄屏上下排列 |
| 商业发票及装箱单办理 | 单证样式可为无侧栏页保留额外列宽 | V4.7.6 第 2 项局部修复已纳入开发，后续以公共容器状态合并判断 |

建议由现有页面容器统一维护侧栏可见性，业务组件只传递内容和开关状态。桌面侧栏打开时保留已选记录。关闭后焦点回到打开入口。窄屏将预览移到表格下方，固定侧栏占位从布局中移除。提交后按桌面、窄屏、数据为空和角色无权四类场景复验。
