# V4.7.6 草稿覆盖清单

「保存草稿」保存填写数据。对应模块页首的「我的草稿」提供继续填写和删除。后端按当前产品、账户、授权数据范围、入口权限和草稿版本校验。工作数据保存在 `document_drafts`，日志记录入口和版本。用户的业务保存仍使用原表单、原接口和原有版本校验。

| 模块 | 铜入口 | 钴入口 | 正式业务节点 |
| --- | --- | --- | --- |
| 备货计划 | 备货计划列表新建，草稿或退回计划编辑 | 同路径按产品切换 | 完整填写后保存计划，原审批流程随后办理 |
| 入库 | 入库新建、原入库单编辑 | 入库备货新建 | 现有入库提交及独立审批 |
| 备货单 | 已审批计划发起新建，保存已选捆包与取样标记 | 已审批计划发起新建。作业页保存逐袋修改，续填校验批次和袋版本 | 正式创建才领用计划，入库、锁定或检斤仍按作业流程 |
| 装车计划 | 独立新建及编辑，含选择的备货批次 | 新建及可编辑的计划、单证资料 | 正式保存校验状态并分配正式发票号 |
| 车辆到厂登记 | 从派车记录进入到厂资料填报 | 同入口按产品切换 | 正式登记复核车辆状态、司机资料和在厂查重 |
| 装车单 | 从装车计划匹配新建、待审核匹配维护及旧入口 | 整批装车单按已确认装车计划生成。生成前填写的计划与运输资料从计划入口保存 | 匹配和提交由原单据流程完成 |
| 正式出库 | 装车审核后的出库流程申报日期 | 装车审核后的离场申报资料及可更正申报 | 出库记录由原审批生成，库存扣减仍由正式出库审批处理 |
| 盘点 | 新建盘点和盘点观察填写 | 新建盘点和袋级盘点记录 | 快照由正式建单触发，确认差异沿用审批 |
| 许可证 | 新建、编辑和延期申请 | 同路径按产品切换 | 正式保存或提交延期审批，现有额度和日期校验生效 |
| 商业发票与装箱单 | 单证生成前填写的商业发票单价 | 装箱单生成或修订理由 | 生成时按原版本和快照校验，草稿阶段保留输入 |
| 销售计划 | 原新建、编辑表单 | 原新建、编辑表单 | 正式保存与原审批保持衔接 |

草稿关联校验使用选定对象的实际项目、仓库与客户范围。正式提交继续复核货位占用、额度、审批状态和业务必填。来自同一份草稿的正式请求使用同一幂等键，错误或超时后可继续从草稿恢复。并发草稿更新按版本拒绝旧提交。

适用边界

- 备货与装车复用已确认的上游单据。系统自动生成的出库记录、出门证、商业发票文件和装箱单文件由办理入口承担填报，历史文件和正式记录按原版本保留。
- 文件选择和系统即时确认仍使用各自流程。浏览器文件选择器中的本地文件需要重新选择。业务附件及原导入工具的现有存档入口保留。
- 当前授权目录中独立取样和独立检斤为历史兼容权限。现行逐捆、逐袋操作使用备货作业。出门证的生成与签发使用正式出库数据，签发前的原单核对属于即时确认。
- 各细分表单的浏览器实测结果见验收报告。未逐单据复测的分支继续列入验收缺口。
