# 装车单详情确认稿

打开[交互确认稿](loading-detail-proposal.html)，切换阴极铜与氢氧化钴，展开装载明细、关联单据及审批记录。样本来自隔离 TEST 的已出库装车单。底部审核节点选择器单独演示既有权限条件。

| 新版区域 | 阴极铜来源 | 氢氧化钴来源 |
| --- | --- | --- |
| 页首 | 装车单 UUID 对应编号、装车日期、现有流程状态 | 装车单 UUID 对应编号、作业日期、实际装车执行状态 |
| 车辆与归属 | 装车单关联计划、客户合同、装车批次、运输资料与到厂记录 | 出库客户和合同快照、销售计划、备货批次及车辆运输快照 |
| 装载汇总 | 有效装载捆包数、业务净重与毛重。已归档记录用历史快照 | 装车袋数和有效实物净重。预计量与 ARECOMS 实际确认量各自取正式出库关联记录 |
| 装载明细 | 捆包编号、片数、铅封、毛重、净重，沿用当前业务精度 | 袋号、铅封、货位、毛重和净重，沿用袋级检斤与出库快照 |
| 关联单据 | 装车计划、实际备货批次、销售计划、已关联许可证及已生成单证 | 装车计划、备货批次、销售计划、已关联许可证及已生成装箱单 |
| 审批与操作 | 审批和装车事件的时间、动作、操作人及记录意见 | 装车执行事件的状态、时间、操作人及记录意见 |

页首使用返回装车列表、单号、状态及业务日期。授权用户在同一区域看到对应办理按钮。独立审批仍校验提交人与审核人。未关联许可证或单证的样本保留空值。实际实现中的关联单据使用现有权限及直达路径。

| 节点 | 阴极铜 | 氢氧化钴 |
| --- | --- | --- |
| 待装车审核 | 授权审核人执行审核通过或驳回，禁止自审 | 具有装车审核权限的现场主管或管理员执行通过或退回，禁止自审 |
| 已审核待离场 | 具有离场申报权限的人员登记出库流程 | 具有离场申报权限的人员登记实际离场资料 |
| 正式出库 | 已有单证及操作记录可查，出库更正沿用现有入口 | 已有单证、ARECOMS 确认及操作记录可查，按原权限办理 |

窄屏下页首操作换行，汇总按可用宽度排列。装载表格可在表格容器内横向查看，编号和状态保持可读。确认项为首屏字段顺序及明细默认折叠方式。
