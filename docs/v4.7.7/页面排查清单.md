# V4.7.7 全站页面排查清单

[登记路由、产品与状态](../../tests/release/uiux-inventory.json)及[角色、语言与视口矩阵](../../tests/release/uiux-matrix.cjs)用于浏览器扫描。新增历史台账两种产品的列表、详情和普通账号拒绝场景。以下为本版变更与业务复验入口。

| 页面群 | 入口与产品 | 主要检查 |
| --- | --- | --- |
| 登录、注册与账户 | `/`、注册弹窗、`/workbench/accounts`、`/workbench/permissions`，共用 | 登录反馈、注册字段错误、账号弹窗及权限页 |
| 信息总览 | `/overview`，铜钴 | 整数计数、空值、趋势图单位、库存在途和历史依据 |
| 库存查询和档案 | `/inventory`、`/inventory/:id`、钴 `/inventory/:id/archive` | 列表筛选、排序、详情往返，钴业务操作原路径，权限和表头一致 |
| 库存地图 | `/stock-map`，铜钴 | 默认图、首次进入及刷新、缩放、定位、浮动详情、产品切换 |
| 客户、合同、销售计划与许可证 | `/customers`、`/sales-plans`、`/export-licenses`，铜钴 | 筛选、详情、审批操作可达，额度、发票号与履约回归 |
| 入库和备货 | `/receipts`、`/preparation`、`/preparation/work-plans`，铜钴 | 表单、计划、作业、审核弹窗和备货净重 |
| 装车、出库、单证、出门证 | `/loading-plans`、`/outbounds`、`/export-shipments`，铜钴 | 筛选和操作、空右栏、装车锁定与正式扣减、单证流程 |
| 盘点、报表、金属量 | `/stocktaking`、`/reports`、钴 `/cobalt-metal` | 数值格式、盘点过程、ARECOMS 确认与导出 |
| 历史台账 | `/historical-movements`、`/historical-movements/:id`，铜钴 | 管理员上传、预览、重试、作废；普通账号页面和接口拒绝 |
| 系统记录与辅助入口 | `/audit`、`/workbench`、基础资料及相关抽屉 | 路由、授权差异、布局及反馈 |
