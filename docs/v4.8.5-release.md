# 穆松尼 WMS V4.8.5

- 备货计划可在创建时直接提交审核。列表对勾选且有权办理的计划支持一键提交审核和一键审批，同批次操作在一个事务内完成。
- 装车计划自动取号避开有效历史进口单证占用的发票号和装箱单号。装箱单号随发票号在页面联动显示，保存后以服务端最终生成值为准。
- Excel 入库将一位捆包序号补零到两位，原有多位序号保留。
- 已作废的历史装箱单详情停止返回和显示关联业务单据入口。历史库存和出入库列表沿用有效来源过滤。管理员仍可查原表、原文件、作废人、时间和原因。
- 预生产仓库可以通过 `scripts/preproduction-cobalt-map.cjs` 安装已审核的 A、B、C 三个固定库区，共 93 个货位，同时创建临时堆存区配置。脚本使用已有管理员授权并记录变更。存在未审核配置时退出。已有完整配置时安全重跑。
- 迁移仍为 `195_v482_dispatch_vehicle_month.sql`。从 V4.8.4 升级时使用 `deploy/upgrade-preproduction-v483.sh <提交 SHA> v485 <项目代码> <仓库代码> <管理员用户名>`。部署验证备份恢复后，先预演货位安装并回滚，随后安装并复核历史来源状态、钴库存和库存位置。
